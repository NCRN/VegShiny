Species Lists

This page displays comprehensive lists of the vascular plant species found in the National Capital Region parks.

Plants in the Monitoring Plots shows the species recorded during forest monitoring at the selected park, park area, and plot. Lists display the common name, Latin (scientific) name, family, genus, growth habit, and nativity of each species.

All Vascular Plants Known from the Park is a broader reference list including vascular plants from all areas of the park as documented in NPSpecies, the master biodiversity database for the National Park Service. The data shown includes species common name and Latin (scientific) name. To learn how these lists were evaluated and reviewed, or for lists of other species groups, such as birds and mammals, visit the NPSpecies Species List page.

Park Area (optional): Filter to a smaller park area, or view all park areas at once. Only shown for parks with designated smaller park areas (C&O Canal, GW Parkway, National Capital Parks-East).

Plot-selection map: An interactive map for choosing which plots' data feeds the table below it:

  • Individual Plot Selection: Click a single plot to toggle it between selected (shown green) and deselected (shown gray).
  • Multiple Plot Selection: Use the draw-box tool to select many plots at once (clicking this icon first deselects everything, then you draw a box around the plots you want to capture).
  • Select All Plots / Clear All Plots: Buttons that select or deselect every available plot in one click.
  • Plot count: The total number of available plots within the current park and/or park area selection is shown below the map. All available plots are selected by default.
  • Hide/Show Plot IDs: The ID button toggles plot ID labels on or off. Plot IDs are hidden by default.

Advanced Filters: Filter table by:

  • Family: Column is only visible on wider screens.
  • Genus: Column is only visible on wider screens.
  • Growth Habit: Column identifies each species as a tree, shrub, herb, or vine. Some species may have no growth habits or may have multiple.
  • Nativity: Column identifies each species as either native or non-native to the National Capital Region. Nativity does not indicate a species' invasive status.

About the Map

Map displays the results of ongoing forest monitoring (2005-present) by the National Park Service's Inventory and Monitoring program. Each circle represents a permanent forest monitoring plot. Clicking a circle will show the name of the park the plot is in, the plot ID, the year the data was collected, and the type of data displayed.

Alive or Dead: Look at only alive trees, only dead trees, or all trees. Only available when the plant type selected is "Trees."

Map Base Layers: Choose the base map color scheme: neutral, satellite, white, or slate.

Map Data Layers: Adds an additional reference layer on top of the plot markers (Ecoregions, Forested Areas, or Soil Map). Hovering over a layer shows its color key and label.

Hide/Show "No Observation" Plots: The eye icon toggles whether plots with zero observations (under the current filters) are shown. All plots are shown by default.

Hide/Show Plot IDs: The ID button toggles plot ID labels on or off. Plot IDs are hidden by default.

Layer Transparency Slider: Adjusts the opacity of the selected data layer. It is only available when a data layer is selected.

Resize Plot Markers: Adjusts marker size larger or smaller. Size 5x is selected by default.

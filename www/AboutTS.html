Data Trends Over Time

These graphs show how estimates of forest vegetation abundance, size, and plot occupancy have changed across monitoring cycles for a selected park. Each line represents a species (or all species combined), and each point on the line represents the mean value for that species during a given monitoring cycle. Confidence intervals (CI) are represented by opaque ribbons and are optionally shown on the figure. A graph and data table are available for download.

Display 95% Confidence Intervals: Toggles whether each species' CI ribbon is shown.

When only one monitoring plot exists for a park during a given cycle, confidence intervals can't be estimated; they are shown as NA in the table and omitted from the figure.

Line Thickness: Slider adjusting the trend line thickness.

CI Ribbon Opacity: Slider adjusting the opacity of the confidence interval ribbons.

Color Palette: Choose from four palettes for species color assignment in the figure.

Legend click behavior:

  • Single-click a legend label to remove that species from the figure (click again, or change any input, to restore it)
  • Double-click on one legend label to isolate that species and hide all others (double-click again to restore all)

Order table by: Sort the data table by species first or by cycle first.
